Mandá documentos para firmar

Subí el PDF, copiá el link y mandáselo al cliente (por WhatsApp o mail). El cliente lo abre en el celular, escribe sus datos, firma a mano y te devuelve el PDF firmado.

1 Conectar con GitHub Sin conectar

Los PDF se guardan cifrados en tu repositorio de GitHub (nadie puede leerlos sin el link). Para subirlos desde acá hace falta un token con permiso sobre ese repositorio. Se hace una sola vez y queda guardado sólo en este navegador.

  1. Abrí GitHub › Generar token (fine-grained token).
  2. Token name: «Firma de documentos». Expiration: la que prefieras (por ejemplo, 1 año).
  3. Repository access › Only select repositories › elegí tu repositorio.
  4. Permissions › Repository permissions › Contents: Read and write.
  5. Generate token, copialo y pegalo acá abajo.

2 Preparar un documento y marcar dónde firma

Elegís el PDF, decidís si el cliente firma una vez, en todas las hojas (una firma distinta por hoja) o donde vos marques. Cada firma se ubica sola debajo del texto y la podés mover. Después generás el link.
